# Instruction Precedence

1. Record each instruction file, its scope, and the files it governs.
2. Separate organization policy, repository policy, subtree policy, host adapter, contributor guidance, and descriptive documentation.
3. Identify exact contradictions, duplication, stale paths, and unenforced claims.
4. Preserve higher-authority safeguards and legitimate narrower subtree rules.
5. Propose a canonical home for each policy and link to it from adapters.
6. Obtain approval before superseding, deleting, or weakening an instruction.

Do not pretend different hosts share the same precedence semantics. State effective behavior for each supported host.
