# Traceability

Support many-to-many relationships:

- One PRD has many requirements and issues.
- One requirement may require multiple issues.
- One issue may cover multiple related requirements.
- Work may span repositories.
- PRs, tests, and acceptance evidence may partially or fully satisfy an issue.

Maintain stable links from evidence → objective → requirement → acceptance criterion → issue → PR → test → validation. Classify coverage as planned, partial, implemented, validated, blocked, superseded, or retired.
