# Segmentation and ICP

Define segments by shared problem, buying context, and reachability—not broad demographics alone.

Score problem intensity, urgency, willingness to pay, reachability, product fit, available proof, expansion potential, and cost to serve. Recommend a beachhead only when it has a credible route to learning and revenue.

For each selected segment, define:

- Organization or customer characteristics
- End user and economic buyer
- Technical or security evaluator
- Influencers and blockers
- Trigger events
- Current alternatives
- Objections and purchase criteria
- Expected sales cycle and implementation effort

Explicitly name deferred segments and the evidence that would justify reconsideration.
